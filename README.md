It takes a picture of your own screen, reads the items in the Murder Mystery 2
trade window, looks up their values and adds them up. Both sides, live, while
you trade.

**It is free. It stays free.** It only asks for a key, and the key comes from
the Discord — one message, ten seconds.

## What it is not

Not an exploit. Not a script. Not an injector. Not a hack.

It does not click for you. It does not type for you. It never sends anything to
Roblox and it does not know your account exists. **Nothing goes into the game,
ever.** Anything it does, you could do by hand with a value list open on your
phone — it just does the adding, in half a second, without you looking away
from the trade.

## Getting started

1. **[Download it](https://github.com/philippearchambault/MM2TradeLens/releases/latest/download/TradeLens.exe)** — one file, nothing to install
2. **[Join the Discord](https://discord.gg/kqVU9HHP3f)** and type `?getkey` in any channel
3. Paste the key into the program, press **START**, and trade

## Windows will warn you, and that is normal

*"Windows protected your PC"* appears for every program whose author has not
paid for a signing certificate, which is most small tools. Click **More info**
→ **Run anyway**. If you would rather check first, drop the file on
[virustotal.com](https://www.virustotal.com).

## Updating does not reset anything

Your key, your inventory and your settings live in your own Windows folder, not
inside the program. Download the new file over the old one — everything is
still there.

## What it does

| | |
|---|---|
| Reads both sides of the trade live | Item names, Chroma tags, and how many of each |
| Prices them | MM2 Values or Supreme Values, your choice, kept current |
| Tells you the gap | *"add 3 200 more"* — measured against the goal you picked |
| Suggests what to put in | Or not: turn it off and it just shows the values |
| Prices your own inventory | While the trade is open, so you can pick by reading |
| Saves a picture of the trade | One button, already copied — paste it in Discord |

## Questions

**Can I get banned?** No. Nothing is sent to Roblox. It reads pixels on your
own screen, the way a friend sitting next to you would.

**Does it need my Roblox account?** No. It never asks, and it would have
nothing to do with it.

**Does it work on Mac?** Not yet. Windows only.

**Why does it need a key?** Because that is how the people using it end up in
the same place — the Discord — where the value lists, the updates and everyone
else's catches are. The program is free either way.
